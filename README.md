# Sistema de Financiamento Imobiliário

Projeto desenvolvido em Java para a disciplina de Fundamentos da Programação Orientada a Objetos.

## Estrutura

src
├── modelo
│ └── Financiamento.java
├── util
│ └── InterfaceUsuario.java
└── main
└── Main.java

## Funcionalidades

- Cadastro de financiamentos
- Validação de dados
- Cálculo de pagamento mensal
- Cálculo do valor total do financiamento
- Uso de ArrayList
- Soma dos valores dos imóveis
- Soma dos valores dos financiamentos
